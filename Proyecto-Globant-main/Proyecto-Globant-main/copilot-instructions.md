# Instrucciones del proyecto

- Antes de proponer cambios, inspecciona la estructura, el código y la documentación existentes para identificar el stack y las convenciones del proyecto.
- No presupongas tecnologías ni añadas dependencias sin una necesidad concreta.
- Mantén los cambios enfocados y coherentes con los patrones existentes.
- Ejecuta las pruebas, comprobaciones o validaciones disponibles que correspondan a los archivos modificados.
- Si el workspace todavía no contiene implementación, confirma los requisitos antes de elegir una arquitectura o crear una aplicación.
